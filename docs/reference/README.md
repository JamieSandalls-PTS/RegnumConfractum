# Art references (stakeholder-approved, 2026-08-17)

The canonical references for character model, animation, and clothing work.
Every modelling round is verified against these in all 8 facing directions
(contact sheets in `docs/media/`), per the stakeholder's workflow ruling.

## Canonical references supplied by the stakeholder (in chat, 2026-08-17)

These were provided as chat attachments and are **not** stored here (drop
them in if convenient):

1. **Clothing hood** — photo of a bearded man in a brown monk's hood: the
   cowl frames the face and leaves it fully visible, draping in folds around
   the head and pooling on the shoulders. The clothing hood must look like
   this — never a face-covering void.
2. **Female walk cycle** — 8-frame side-view illustration of a young woman
   walking: relaxed arm swing, moderate stride, upright carriage. Canonical
   for the female walk.
3. **"Go hooded" (D-219 concealment)** — photo of a woman in a black hood
   with a lower-face veil: eyes visible, nose/mouth masked, hood draped to
   the shoulders. The deliberate concealment presentation looks like THIS —
   hood + veil — not a shadow blob.
